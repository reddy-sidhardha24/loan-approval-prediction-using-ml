
# Loan Approval Prediction Using Machine Learning

A Python-based machine learning project that predicts loan approval status using applicant details and compares multiple classification algorithms to identify the best-performing model.

## 📌 Project Overview

The **Loan Approval Prediction System** uses historical loan application data to predict whether a loan application is likely to be approved or rejected. The project includes data preprocessing, model training, performance evaluation, visualization, and prediction report generation.

Three machine learning algorithms are implemented and compared: Logistic Regression, Decision Tree, and Random Forest. The best-performing model is selected based on accuracy and saved for future predictions.

## ✨ Features

- **Data Preprocessing:** Handles missing values, duplicate records, and categorical data encoding.
- **Model Comparison:** Compares Logistic Regression, Decision Tree, and Random Forest.
- **Model Evaluation:** Calculates accuracy, precision, recall, and F1-score.
- **Data Visualization:** Displays loan approval distribution, confusion matrix, and feature importance.
- **Loan Prediction:** Accepts applicant details and predicts loan approval status.
- **Prediction Confidence:** Displays the model's estimated probability for the predicted class.
- **Applicant Comparison:** Compares selected applicant details with dataset averages.
- **Report Generation:** Saves model comparison results and prediction reports.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Data Visualization:** Matplotlib, Seaborn
- **Model Serialization:** Joblib
- **Dataset Format:** CSV

## 🤖 Machine Learning Algorithms

| Algorithm | Purpose |
|---|---|
| Logistic Regression | Classification of loan approval outcomes |
| Decision Tree | Rule-based classification using applicant features |
| Random Forest | Ensemble-based classification using multiple decision trees |

The system compares model performance and selects the model with the highest test accuracy.

## 🔄 Project Workflow

1. Load the loan application dataset.
2. Preprocess the data and encode categorical variables.
3. Split the dataset into training and testing sets.
4. Train and compare the three classification models.
5. Evaluate model performance using classification metrics.
6. Visualize loan distribution, confusion matrix, and feature importance.
7. Collect applicant details and generate a prediction.
8. Compare selected applicant values with dataset averages.
9. Save the prediction report.

## 📊 Evaluation Metrics

- **Accuracy:** Measures the proportion of correct predictions.
- **Precision:** Measures the proportion of positive predictions that are correct.
- **Recall:** Measures the proportion of actual positive cases correctly identified.
- **F1-Score:** Represents the harmonic mean of precision and recall.
- **Confusion Matrix:** Summarizes actual and predicted classifications.

Actual performance depends on the dataset and the trained model. No fixed accuracy is claimed in this README.
